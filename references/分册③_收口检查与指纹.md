**修复回复「待复核清单」模板钩子**（两问从"靠人自觉"变"每轮必答"）：
每轮修复回复的待复核清单**必须含两句**——①「本轮新闸/改闸，拿真发布件或册子产物形态夹具跑过没有？该放的过、该拦的拦，两侧读数各是什么？」②「本轮改的判据所指向的闸，其能力边界与判据命名的风险是否匹配？」（复核方法论常设判据两问的落地动作；挂在复核模板对位——适用对象是修复/复核环节，不是发布执行者）。
**留档对拍格（嵌码联检第 1c 格，开发期专属）**：开修 cp 留档后，联检**断言留档件 sha == 账载源版本终值**。现行算法（以代码为准）：①**源版本从留档目录名解析**（`_vX定稿_`／`_vX重开_`／`_vX返工_`）；②**期望源版本＝开发账"当前版"的前一行**（结构关系，不靠散文词）；③**比对面＝账载点到的那几件**——账载有、档内无＝缺件 FAIL；档内有、账载无＝标记件只列出不判；④缺 `_历史`/开发账时：**默认关**，只打印"未启用"、不计 PASS/FAIL；**显式 `--dev-archive` 却缺账 → FAIL 点名，不静默降级**。

**使用前提（必修 2）**：对外包**只有出货账 `FINGERPRINTS.md`（平表：文件/字节/sha）**，结构上**没有**开发期所需的 `_历史` 与开发账。想让本格真跑，须在**副本**里自建：
- 目录：`_历史\_v<版本>重开_<日期>\`（把本轮开修前的件整件拷进去）；
- 开发账：**根目录 `DEV_LEDGER.md`**（与出货账 `FINGERPRINTS.md` 职责分开：一个记沿革、一个记出货指纹）。

**`DEV_LEDGER.md` 最小样例**（照这个骨架写即可）：

```markdown
# 开发账

版本 **v0.2.0**

## 一、说明
开发期内部账，不入发布包。

## 二、当前件
- SKILL.md `0123456789ABCDEF`

## 三、版本沿革
- **v0.1.0（首发）**：SKILL `FEDCBA9876543210`；README `0011223344556677`
- **v0.2.0（重开）**：SKILL `0123456789ABCDEF`
```

> 读法：`版本 **vX.Y.Z**` 头＝当前版；`## 三、` 下每行以 `v` 开头，行内 `短名 \`16位sha\`` 为键位；期望源＝当前版前一行。

**立牌（必须写进使用说明，不许只留在代码里）**：本格是**开发期专属闸**，成品位结构上没有 `_历史` 与开发账，**在成品位显式开启会 FAIL（exit 1）并点名缺账**——使用者勿在成品位开启；开发期请在副本按上方样例建账后开启。
**禁止按旧语义理解本格**：不得再写成"从沿革'当前版'行读终值"——那是已退役的旧算法，与现行代码不同义。依据＝多轮留档证据链（假档／声称已建实际未建／先改后拷当场逮）——**"我拷了"和"拷对了"是两件事，格断言后者**；忘了对拍也会被 FAIL 提醒。本格不替代"先 cp 再改"动作（动作仍人工），只让"拷了但没拷对/没拷"当场炸。

**复核方法论常设判据（假绿教训）**：**"闸能力是否覆盖判据所命名的风险"**——
每轮修复/复核不只查"册子和实现说法一致"（措辞层），还要查"**判据让你跑的那道闸，真能逮住它说的那个风险吗**"（能力层）。
教训实例：曾要求"注入后必重跑英文验收"，但 en_check 当时无 CJK 检测——照判据走照样放绿（措辞拧准了≠风险被覆盖）。
每轮复核清单加问一句：**本轮改的判据所指向的闸，其能力边界与判据命名的风险是否匹配？不匹配即立牌，闸与判据同修。**

**复核方法论常设判据第二问（精确率侧）**：**"闸的豁免口径，是否覆盖判据自己强制产生的合法形态？"**
召回侧之外补精确率侧——新闸落刀当场，拿真·发布件（或册子产物形态夹具）跑一遍：**该放的过不过、该拦的拦不拦。**
教训实例（三案实锤）：check_cjk 豁免只认反引号，把分册① 必选的 `assets/截图/` 合法路径全逮住（干净件本身 FAIL＝判据相容性破裂）；restyle 语言警告无署名豁免，被分册② §1 第 7 段强制的署名收尾压死恒不触发；en_check selftest 从不进 main()，无 `--terms` 崩溃无人测。
**selftest 夹具纪律**：**新增闸的用例夹具必须取册子规定的产物形态或真发布件片段，不许自造理想最小件**——
三个新 selftest 用例全挑"能过的形态"、回归全绿指纹全对而三层里两层在真件上是死的：**回归全绿与真件可用之间，隔着夹具形态与被测产物形态同源那条缝。**

**执行者自建检查器纪律（实测产出，"文"不加闸）**：
**"验法也归验法管"**：执行者为过闸自建的检查器，其本身也是验法——必配真件形态夹具自测（selftest 夹具纪律同源）；
**改验法口径必须公开改动与副作用，不悄悄改**。判别句："改判据让数字好看＝绕过；改判据因判据错＝修——两种长得一模一样，唯一自保＝公开。"
（实案：某收口检查器三假阳性，口径修正记录写进证据而非静默改码——公开即从"绕过嫌疑"变"修"）
**"否定权"（原则性条文，不做机械断言）**：查做分离的深化——单人执行缺的不是"再读一遍"，是"**一个不参与生产的人的否定权**"：
有权说这是错的、且必须改。B 类人判项挂起、外部复核、委托人验收都是它的落点。
（实案：9 条挂起的实质风险量化——"把包做到可发"与"替你发版"之间那口气是留给人的）

**输出件判据**：
**每个闸口过闸＝盘上有对应输出件**，不是"跑过了"算过——tests/清单/指纹/英文验收/美化/自检六类闸，
原始输出（stdout/stderr 重定向）落 `_过程件\`（如 `tests_out.txt`、`fp_check_final.txt`）；
     **编码铁律**：
     调 skill 脚本统一 `python -B -I -X utf8`（`-X utf8` 不受 -I 影响；**`-B` 免生 `__pycache__`**，否则 ⓪ 第一条命令就把包弄脏、紧随的 `--check` 必判净空违例）；stderr 重定向落盘后
     **读文件时显式 encoding="utf-8"**（Windows 重定向默认 ANSI，按 utf-8 读即乱码——证据乱码＝证据受损）；
     **落证据禁走 Out-File 管道**（`python xxx.py | Out-File -Encoding utf8`
     在中文 Windows 上 PowerShell 先按 ANSI 解码子进程输出，`-Encoding utf8` 救不了已经坏的字节）**：
     **子进程 stdout/stderr 直接以二进制落盘**（推荐样例：自写十余行 `run.py`，`subprocess` 捕获 bytes →
     原样写文件；读回时显式 utf-8 解码）——证据是字节，先保字节再谈编码；
并在收口检查单对应项注明输出件文件名；**没有输出件的闸按未过处理**。
"人判 PASS"字样一律写"**待人判，未判**"——防止下一个读的人以为真的有人看过。

**封包触发权纪律（对内，不对用户念）**：**清理与封包的触发权在用户——AI 不自判"做完了"；用户未确认前，过程件全留。**
对用户只说权利句（分册④ §3.2）："这次的活到这儿算齐了吗？——你说了算……"；纪律原句进本册，不进交互话术。

**挂起项登记位**（查做分离×单人降级的落点）：
单人执行（纪律第 5 条降级）或无人可问时，B 类人判项、单人自检项、待补审项**不许直接打 PASS**，
逐条登记在下表并随 FINGERPRINTS 留档：

```
| 挂起项 | 涉及检查单项 | 现象/根因 | 谁来解决 | 已销项? |
|---|---|---|---|---|
| （无挂起也要写一行"无"——空表＝没过脑子） |
```

## §2 指纹收尾（第⑦步）

1. **FINGERPRINTS.md** 由探针对盘实算生成，**不是手抄**：
   - 分发 zip 一节（字节＋SHA256 全值＋CRC 结论＋zip 内构成）；
   - 源码四件"zip 内原件 vs 本目录对外件"对照（不同处**立牌说明**——如双 README 各司其职）；
   - 文档/资产/插件各一节（SHA256 前 16）；
   - 总件数（含统计口径：排除哪些、packages 怎么计）；
   - **清单与 N/A 联动**：`checklist_check.py --stage final` 对条件件缺失和分发 zip 缺失，只认本账 `## 条件件 N/A 立牌` 专节的逐件精确登记（`- **\`件名\`**：N/A（原因）`）；散文、跨件子串、必选件 N/A 均不豁免。pre 阶段的 zip/账待生成 WARN 与 final 缺件 FAIL 分开，互不混码。
2. **标准探针**（复制下方代码落盘为 `fingerprints_scan.py` 再跑，用完按用户拍板处置）：
   ⚠ **包内脚本直用**：包里已带 `scripts/fingerprints_scan.py` 原件——
   **包内脚本即本节嵌码同物（selftest 已机械验同步），直接用它，不必再抄本节代码**。
   本节嵌码是给"没有脚本目录的裸 md 形态"用的兜底；两处并存是双源设计，抄写步骤对包执行者是冗余。
   ⚠ **嵌码同步校验**：本节嵌码＝`scripts/fingerprints_scan.py` 的**全文复制**
   （双源）——**任何一边改动必须另一边同改**，其同步校验由本节 §2.1 嵌码联检
   `selftest_4tools` 的**嵌码一致性用例承载**（自动 diff 本节嵌码与脚本文件，不一致即 FAIL 退出——
   **探针本体没有 `--selftest` 开关，别照旧口径跑它**：旧文"并跑 --selftest 机械校验"
   是一条跑不通的命令，实跑 exit 2）；
   "两处同改"靠人肉记着曾是漏改风险，现在由该用例结构性兜住；
   **四脚本**各带 `--selftest`（en/restyle/checklist/text_quality），探针走 `--check`；第⓪步阻断式预检含"四脚本 selftest 全过＋嵌码联检全过才开工"。第五支文字质量脚本由自身 selftest＋全包扫描覆盖，不硬塞进历史四工具联检。

# -*- coding: utf-8 -*-
"""fingerprints_scan.py v3 —— 扫描/校验双模式；两模式输出互相接头；zip 专节自动化。

口径：排除 .git node_modules dist .venv venv _历史；
      __pycache__ 目录与 *.pyc/*.pyo 不排除——升格为"净空违例"点名（W5-a，某轮返工：
      原先留在 EXCLUDE_DIRS 使特判不可达，G16 场景静默 exit 0）；
      排除文件 Thumbs.db desktop.ini .DS_Store。
安全：盘上路径一律 os.walk 自产；表内路径只做解析后的精确登记，不拿子串冒充登记。

v3 新增（#20/#26/#30 修）：
  · scan 遇 .zip 自动生成「分发 zip 专节」：zip 本体行＋CRC 行＋zip 内件行
    （arc 名带 zip: 前缀、SHA256 全值）——zip 内件从此由探针自动登记，
    人不再手写（手写 zip 内件与根件同名撞车的坑结构性消失）；
  · check 识别 zip: 前缀行：从 zip 内读取该件复算，不经盘上路径；
  · 报告口径区分「表行条目」（含对照扩展行与 zip: 行）与「盘点实物件」，
    并附口径说明（68 vs 67 误读的修法）。
"""
import hashlib
import os
import re
import sys
import zipfile

EXCLUDE_DIRS = {".git", "node_modules", "dist", ".venv", "venv", "_历史"}  # W5-a（四格夹具）: __pycache__ 移出——否则 L39 特判不可达死代码（G16 未闭合）
EXCLUDE_FILES = {"thumbs.db", "desktop.ini", ".ds_store"}
SELF = "FINGERPRINTS.md"   # 自身不入表（自指哈希不可能成立），默认豁免漏登记检查


def normalize(rel):
    return rel.replace("\\", "/")


def iter_inventory(root):
    """盘点索引。W5 修（早期修订）：__pycache__/*.pyc 不再静默排除——单独收集为"净空违例"
    （早期某轮 G16 实锤：运行期长出 __pycache__ 曾被误判 PASS，习惯推断不是判据，
    只能数出来）。返回 (inventory, violations)。"""
    root_abs = os.path.abspath(root)
    inventory = {}
    violations = []
    for dirpath, dirnames, filenames in os.walk(root_abs):
        if "__pycache__" in os.path.basename(dirpath):
            violations.append(normalize(os.path.relpath(dirpath, root_abs)) + "/（__pycache__ 目录）")
            dirnames[:] = []
            continue
        dirnames[:] = [d for d in dirnames if d not in EXCLUDE_DIRS]
        for f in filenames:
            if f.lower().endswith((".pyc", ".pyo")):
                violations.append(normalize(os.path.relpath(os.path.join(dirpath, f), root_abs)) + "（字节码残留）")
                continue
            if f.lower() in EXCLUDE_FILES:
                continue
            full = os.path.join(dirpath, f)
            inventory[normalize(os.path.relpath(full, root_abs))] = full
    return inventory, violations


def sha256_bytes(data):
    return hashlib.sha256(data).hexdigest()


def sha256(path):
    h = hashlib.sha256()
    with open(path, "rb") as fh:
        for chunk in iter(lambda: fh.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def _open_zip(path):
    """打开 zip；损坏/不可读＝输入环境错：一句人话＋返回 None（审查修正：
    退出码三态承诺“2＝用法或输入环境错，不甩 traceback”）。调用方见 None 即中止。"""
    try:
        return zipfile.ZipFile(path)
    except (zipfile.BadZipFile, OSError) as e:
        print(f"ERROR zip 无法读取：{path}（{e.__class__.__name__}）——重下或删掉后重跑",
              file=sys.stderr)
        return None


def zip_section_lines(zip_path):
    """对一个 zip 生成专节行：本体行＋CRC 行＋zip 内件行（zip: 前缀＋全值哈希）。"""
    z = _open_zip(zip_path)
    if z is None:
        return None
    lines = []
    with z:
        crc_bad = z.testzip()
        crc_text = "CRC 全验 PASS" if crc_bad is None else f"CRC FAIL（{crc_bad}）"
        names = [n for n in z.namelist() if not n.endswith("/")]
        # 注释行放表格流之外（本段首行）——真机实测反馈：`# ↑` 插在表格中间会打断 markdown 表，
        # zip: 行变成无表头表格（"整段可粘"与"渲染可用"之间有缝）。
        lines.append(f"# 分发 zip 专节（探针自动生成）：内件 {len(names)} 件，{crc_text}，"
                     f"内件 arc 名带 zip: 前缀、SHA256 全值；下表为本体行＋内件行")
        lines.append(f"| `{os.path.basename(zip_path)}` | {os.path.getsize(zip_path):,} | "
                     f"`{sha256(zip_path).upper()}` |")
        for info in sorted(z.infolist(), key=lambda i: i.filename):
            if info.filename.endswith("/"):
                continue
            data = z.read(info.filename)
            lines.append(f"| `zip:{info.filename}` | {len(data):,} | "
                         f"`{sha256_bytes(data).upper()}` |")
    return lines


def scan_print(root):
    inv, _viol = iter_inventory(root)
    rows = [(rel, os.path.getsize(full), sha256(full)) for rel, full in sorted(inv.items())]
    print("| 文件 | 字节 | SHA256（前 16） |")
    print("|---|---|---|")
    zips = [rel for rel, _, _ in rows if rel.lower().endswith(".zip")]
    _pending_hdr = False  # zip 专节打断了主表：下一个普通件行前要补表头（真机实测反馈）
    for rel, size, digest in rows:
        if rel == SELF:
            continue
        if rel in zips:
            # zip 本体行由专节生成（含全值哈希），不再打严格行——避免同名行（同名撞车坑）
            # 真机实测反馈：专节注释行插在表格中间＝lazy continuation 把表吞成纯文本。
            # v3.0.1 小深复核定版顺序：**注释 → 空行 → 表头 → 分隔 → 数据行**（v1/v2/v3 三版
            # 都把注释留在表头之后，表照样被注释打断——"表数对"是代理指标，
            # 语义判据＝行必须在表里：每表 tbody ≥1 行、渲染无 <p>| 管行）。
            print("")
            sec = zip_section_lines(inv[rel])
            if sec is None:
                return 2
            print(sec[0])  # 注释行先出（在表头之前，不进表格流）
            print("")  # 空行断开注释与表
            print("| 文件 | 字节 | SHA256（前 16） |")
            print("|---|---|---|")
            for line in sec[1:]:
                print(line)
            print("")
            _pending_hdr = True  # 若后面还有普通件行，先补表头再打行；没有则不悬空表头
            continue
        if _pending_hdr:
            print("| 文件 | 字节 | SHA256（前 16） |")
            print("|---|---|---|")
            _pending_hdr = False
        print(f"| `{rel}` | {size:,} | `{digest[:16].upper()}` |")
    n_files = len(rows) - (1 if SELF in inv else 0)
    n_zip = len(zips)
    print(f"\n# 实物件 {n_files} 件（FINGERPRINTS.md 自身不入表；含分发 zip {n_zip} 个，"
          f"其 zip: 内件为虚拟行不计实物）")


def check(root):
    # 统一口径：根不存在属用法/环境错 → exit 2（缺 FINGERPRINTS 仍是判红 exit 1）
    if not os.path.isdir(root):
        print(f"ERROR 找不到目录：{root}（检查路径，或用 --help 看用法）", file=sys.stderr)
        return 2
    inv, viol = iter_inventory(root)
    # W5：净空违例先点名（__pycache__/*.pyc 静默排除的时代结束——它们现在是 FAIL 证据）
    for v in viol:
        print(f"FAIL 净空违例  {v}")
    if viol:
        print("（W5：以上为运行期残留，清理后重跑；发布目录不该有它们——分册③ 第 15 项判据）")
    if SELF not in inv:
        print("FAIL: 找不到 FINGERPRINTS.md")
        return 1
    text = open(inv[SELF], encoding="utf-8").read()
    # 表头结构自检：--check 只验数值对得上，验不了表能不能渲染——分隔行必须独占一行
    header_bad = 0
    for i, ln in enumerate(text.splitlines(), 1):
        s = ln.strip()
        if s.startswith("|---") and re.fullmatch(r"\|(?:[-: ]+\|)+", s) is None:
            print(f"FAIL 表头粘行  FINGERPRINTS.md:L{i} 分隔行未独占一行（渲染会坏）")
            header_bad += 1
    # 表前起块自检：Markdown 表格必须从块首开始——紧跟引用块/段落行会被并成纯文本（渲染坏）。
    # 与"分隔行独占一行"是两个形态：前者表还在、只是行坏；后者整表被吞、肉眼却像没问题。
    lines_all = text.splitlines()
    for i, ln in enumerate(lines_all):
        if re.fullmatch(r"\|(?:[-: ]+\|)+", ln.strip()):
            if i >= 2 and lines_all[i - 2].strip() != "":
                print(f"FAIL 表头未起块  FINGERPRINTS.md:L{i + 1} 表格前缺空行（表会并进上一段，渲染坏）")
                header_bad += 1
    entries = []          # (rel, size, digest, is_zip_arc)
    for m in re.finditer(r"`([^`]+)`\s*\|\s*([\d,]+)\s*\|\s*`([0-9A-Fa-f]{8,64})`", text):
        rel = normalize(m.group(1))
        if rel.startswith("zip:"):
            entries.append((rel, int(m.group(2).replace(",", "")), m.group(3).upper(), True))
        else:
            entries.append((rel, int(m.group(2).replace(",", "")), m.group(3).upper(), False))
    if not entries:
        print("FAIL: FINGERPRINTS.md 里没解析到表行")
        return 1

    ok = bad = missing = 0
    declared = set()
    # 审查修正：zip 名单预开缓存（with 正确关闭句柄，替换生成器内裸开＋死变量）；
    # 损坏 zip＝输入环境错 → 一句人话 + 中止 exit 2。
    zip_names = {}
    for r, full in sorted(inv.items()):
        if not r.lower().endswith(".zip"):
            continue
        z = _open_zip(full)
        if z is None:
            return 2
        with z:
            zip_names[r] = z.namelist()
    for rel, size, digest, is_arc in entries:
        declared.add(rel)
        if is_arc:
            arc = rel[4:]
            zrel = next((r for r in inv if r.lower().endswith(".zip")
                         and arc in zip_names.get(r, [])), None)
            # R1 修：全路径 inv[r]（相对路径在非目标 cwd 下崩，实跑逮出）
            if zrel is None:
                print(f"FAIL 缺件  {rel}（zip 内无此 arc 名，或目录中无对应 zip）")
                missing += 1
                continue
            z = _open_zip(inv[zrel])
            if z is None:
                return 2
            with z:
                data = z.read(arc)
            real, rsize = sha256_bytes(data), len(data)
            if real.upper().startswith(digest) and rsize == size:
                ok += 1
            else:
                print(f"FAIL 出入  {rel}  表:{digest}/{size:,}B  实算:{real[:len(digest)]}/{rsize:,}B")
                bad += 1
            continue
        if rel not in inv:
            print(f"FAIL 缺件  {rel}")
            missing += 1
            continue
        full = inv[rel]  # 路径取自盘点索引；表内字符串只做比对，从不拼读取路径
        real, rsize = sha256(full), os.path.getsize(full)
        if real.upper().startswith(digest) and rsize == size:
            ok += 1
        else:
            print(f"FAIL 出入  {rel}  表:{digest}/{size:,}B  实算:{real[:len(digest)]}/{rsize:,}B")
            bad += 1

    # CRC 复验：目录内每个 zip 全验一次
    crc_fail = []
    for r, full in sorted(inv.items()):
        if r.lower().endswith(".zip"):
            z = _open_zip(full)
            if z is None:
                return 2
            with z:
                badmember = z.testzip()
            if badmember is not None:
                crc_fail.append(f"{r}:{badmember}")
    if crc_fail:
        print("FAIL CRC  " + "；".join(crc_fail))

    # 反向对拍：实物必须各有自己的精确表行。路径只被说明文字提到不算登记。
    leak = 0
    for rel in sorted(inv):
        if rel == SELF or rel in declared:
            continue
        print(f"FAIL 漏登记  {rel}（各有精确表行才算登记；子串命中不算）")
        leak += 1

    # M3 修（代码审查）：zip 内件反向对拍——表里没有的 arc 一律 FAIL。
    # 只更新 zip 本体行、不登记新增内件时，旧版会报"表盘一致"（ghost.txt 实案）。
    declared_arcs = {rel[4:] for rel, _s, _d, is_arc in entries if is_arc}
    unreg = 0
    for r, full in sorted(inv.items()):
        if not r.lower().endswith(".zip"):
            continue
        z = _open_zip(full)
        if z is None:
            return 2
        with z:
            for arc in z.namelist():
                if arc.endswith("/"):
                    continue
                if arc not in declared_arcs:
                    print(f"FAIL 漏登记  zip:{r}!{arc}（zip 内有、表内无）")
                    unreg += 1

    counted = len(inv) - (1 if SELF in inv else 0)
    declared_physical = {rel for rel, _s, _d, is_arc in entries if not is_arc}
    count_mismatch = len(declared_physical) != counted
    if count_mismatch:
        print(f"FAIL 总件数  表内实物行 {len(declared_physical)} / 盘点实物 {counted}（不计 zip: 内件）")

    print(f"\n复算表行 {len(entries)} 项：PASS {ok} / 出入 {bad} / 缺件 {missing}"
          f"（表行含对照扩展行与 zip: 内件行，可多于实物件数——口径说明，非误读）")
    print(f"反向对拍：漏登记 {leak} 件；zip 内件漏登记 {unreg} 件；"
          f"总件数 {'一致' if not count_mismatch else '不一致'}；盘点实物 {counted} 件（zip: 行为虚拟行不计）")
    clean = (bad == 0 and missing == 0 and leak == 0 and unreg == 0 and header_bad == 0
             and not crc_fail and not viol and not count_mismatch)
    print("结论：" + ("表盘一致" if clean else "有出入，见上"))
    return 0 if clean else 1

### §2.1 四脚本自检段（md 内嵌代码块，复制落盘即跑）

**为什么是内嵌代码块不是脚本文件**：部分宿主平台对探测类脚本落盘零容忍——自检段放 md 里复制落盘执行，落盘零阻力。**第⓪步阻断式预检**用它：四脚本自检全过才开工；skill 本体每次改动后也跑它（嵌码同步校验在其中，改脚本忘改分册＝FAIL 结构性兜住）。

**用法**：复制下方代码落盘为 `selftest_4tools.py`，然后 `python -B -I -X utf8 selftest_4tools.py <skill根目录>`（全口径 `-I -X utf8`，与嵌码 usage 一致；**留档格是开发期专属闸**：默认关，只打印"未启用"、不计 PASS/FAIL；开发期在副本加 `--dev-archive` 显式开启，**成品位不带**〔结构上无 `_历史`，显式开启会 FAIL 并点名缺账，不静默降级〕；临时目录自足 fixture，不触任何原件；脚手架留痕不清）。块内三反引号一律 chr(96) 构造——正则字面量含三反引号会截断 md 代码块。
> **注脚（为什么是"四脚本 selftest＋四工具联检"）**：
> 早期版本⓪步写"四脚本各跑 `--selftest`"——但 fingerprints_scan 无独立 `--selftest`（其自检由本段
> `selftest_4tools.py` 联检承载），字面照抄必踩空（双源实锤，作者第一脚即踩）；曾有人把这句旧写法
> 当成现行要求（读感被绊，执行未偏）——故主件⓪步判据栏只写可执行正解，反例与历史
> 一律收档到本注脚，**判据栏正文不出现反例字样**（判据工学：反例引用是新读者的噪音源）。

        for c in iter(lambda: f.read(1 << 20), b""):
